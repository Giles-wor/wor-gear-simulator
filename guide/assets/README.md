# 공략 이미지 올리는 법

이 폴더에 이미지를 넣기만 하면 공략 탭 그리드에 **자동으로** 카드가 생깁니다.
(코드 수정 불필요 — `guide/data/guides.ts` 가 폴더를 스캔합니다.)

## 폴더 규칙

```
guide/assets/
├─ titans/                ← 카테고리: "타이탄"
│  ├─ 오로라/             ← 항목(카드) 제목 = 폴더명
│  │   ├─ 01.jpg          ← 갤러리 1번
│  │   ├─ 02.jpg          ← 갤러리 2번 (좌우로 넘김)
│  │   └─ 03.jpg
│  └─ 발더/               ← 또 다른 카드
│      └─ 01.png
└─ content/               ← 카테고리: "던전 · 레이드 · 콘텐츠"
   ├─ 일일던전/
   │   ├─ 01.jpg
   │   └─ 02.jpg
   └─ 세계보스.jpg        ← 한 장짜리는 폴더 없이 파일만 둬도 됨
```

## 규칙 요약

- **카테고리 폴더**: `titans`, `content` 두 개. (둘 중 하나 아래에 넣어야 노출)
- **항목 폴더명 = 카드 제목**. 한글 폴더명 OK (예: `오로라`).
- 한 항목 안의 이미지는 **파일명 순서**로 넘어갑니다 → `01, 02, 03 …` 처럼 번호를 매기면 정렬이 깔끔합니다.
- 지원 형식: `jpg`, `jpeg`, `png`, `webp`, `gif`.
- 카드 썸네일은 첫 번째 이미지(`01.*`)가 사용됩니다.

## 카테고리/제목 손보기

- 새 카테고리를 추가하거나 라벨을 바꾸려면 `guide/data/guides.ts` 의
  `CATEGORY_ORDER` / `CATEGORY_LABELS` 를 수정하세요.
- 폴더명과 다른 제목을 보이고 싶으면 같은 파일의 `NAME_OVERRIDES` 에 추가하세요.

> 참고: 저장소 루트 `.gitignore` 가 일반 `*.jpg/*.png` 를 무시하지만,
> `guide/assets/` 아래는 예외로 커밋되도록 설정돼 있습니다.
