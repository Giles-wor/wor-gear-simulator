# 길드전(GvG) 리더보드

**공용 코드 1개**를 아는 사람만 열람·수정할 수 있습니다. 내용은 브라우저에서 암호화된 뒤 저장되므로
서버(DB)에는 암호문만 남습니다. 저장하면 **편집자 이름·시각이 로그**로 남습니다.

## 동작 방식
- 코드가 곧 **암호키 겸 식별자**입니다. 행 id = `sha256(코드)`, 내용 = PBKDF2(25만 회) → AES-GCM 암호문.
- 읽기: anon 키로 `gvg_board` 를 조회할 수는 있지만 돌아오는 건 암호문뿐이라 코드 없이는 못 읽습니다.
- 쓰기: `save_gvg_board()` RPC 로만. 서버가 `id == sha256(코드)` 를 검증하므로 남의 코드 행은 덮어쓸 수 없습니다.
- 편집 로그(`gvg_edit_log`)도 편집자 이름·메모가 암호문이고, 시각만 평문으로 서버가 찍습니다.
- 입장하면 그 기기에서 **1일간** 유지되고(로컬 저장), 이후 코드를 다시 입력합니다. `🔒 잠금` 으로 즉시 해제.
- Supabase 프로젝트 URL/anon 키는 길드원 페이지와 **동일 프로젝트**를 재사용합니다 (`../guild/supabase.config.ts`).

## 최초 1회 설정 (Supabase 대시보드)
1. Supabase → **SQL Editor** 에서 [`gvg-setup.sql`](./gvg-setup.sql) 을 **그대로** 실행.
   (코드 해시를 저장하지 않으므로 이 파일을 손볼 필요가 없습니다.)
2. 페이지에 들어가 원하는 공용 코드를 입력 → 빈 보드가 열립니다.
3. `초기 데이터 불러오기` 로 시드 표를 채우거나 직접 입력한 뒤 **저장** 하면 그 코드로 암호화되어 올라갑니다.
4. 길드원에게 코드를 공유하면 끝. (코드를 아는 사람은 열람과 수정이 모두 가능하며 편집 로그에 이름이 남습니다.)

> 코드 변경: 새 코드로 입장하면 빈 보드가 나옵니다. 옛 코드로 들어가 내용을 옮긴 뒤 새 코드로 저장하세요.
> 옛 코드 행은 그대로 남으니 필요 없으면 SQL 로 지우면 됩니다(`gvg-setup.sql` 하단 참고).

## 🚫 블랙리스트 (운영진 전용)
리더보드 화면의 `🚫 블랙리스트` 버튼으로 엽니다. **리더보드 공용 코드와 다른 운영진 코드**로만 열리고, 같은 코드를 넣으면 거부합니다.
- 항목: 인게임 고유 ID · 확인된 닉네임 기록(닉네임+확인 날짜) · 사유 · 추가/수정한 사람과 날짜. 다른 개인정보 칸은 없습니다.
- 검색: 고유 ID, 옛 닉네임을 포함한 닉네임 기록, 사유에서 찾습니다.
- 삭제는 휴지통으로 이동(복구 가능). 추가·수정·삭제·복구마다 편집 로그(편집자·작업·ID, 암호문)가 남습니다.
- 행 id = `sha256('gvg-blacklist:' + 코드)`, 내용은 운영진 코드로 AES-GCM 암호화. 테이블 직접 조회는 막혀 있고 RPC 로만 읽고 씁니다.
- 두 운영진이 동시에 저장하면 서버가 늦은 쪽을 거부하고, 앱이 최신본을 받아 같은 변경을 다시 적용합니다.
- 운영진 코드는 그 탭(sessionStorage)에만 기억합니다. 운영진이 바뀌면 화면의 `코드 변경` 으로 새 코드로 옮기세요.
- ⚠️ 리더보드처럼 처음 보는 코드는 빈 목록으로 열립니다(오타 주의).

**최초 1회:** Supabase SQL Editor 에서 [`blacklist-setup.sql`](./blacklist-setup.sql) 을 그대로 실행(기존 테이블은 건드리지 않고, 다시 실행해도 안전). 그다음 페이지에서 운영진 코드로 열어 첫 항목을 저장하면 그 코드로 목록이 만들어집니다. 코드는 리포에 적지 마세요.

## 번들 시드에 대해
`data/seed.json` 은 최초 부트스트랩용 스냅샷이라 **암호화되어 있지 않고 리포에 공개**되어 있습니다
(이미 커밋 이력에 있어 감춰도 의미가 없습니다). 한 번 저장한 뒤부터의 데이터는 전부 암호문으로만 저장됩니다.
시드가 필요 없어지면 `data/seed.json` 과 App 의 `초기 데이터 불러오기` 버튼을 지워도 됩니다.

## 순위 규칙
- 각 회차(열)의 **순위 칸은 포인트 기준 자동 계산**(내림차순, 동점은 행 순서).
- 편집 중 순위 칸에 값을 직접 넣으면 그 값으로 **수동 보정**(비우면 자동). 이미지의 '예상 결과'처럼 손으로 순위를 지정할 때 사용.
