# 기존 티스토리 정리 체크리스트

`thesimplethings.tistory.com` — 기존 글 약 223개, 애드센스 승인 완료,
2024년 이후 운영 중단, 과거 닉네임 8종 혼재.

이 문서는 도구가 대신할 수 없는 **블로그 관리자 화면에서 직접 해야 하는 작업**
목록이다. 기존 223개 글을 전부 삭제하거나 다시 쓰지 않는다.

---

## 1순위 — 브랜드 통일 (반나절)

이걸 먼저 끝내야 새 글을 올릴 명분이 생긴다.

- [ ] 블로그 이름 변경
- [ ] 프로필 이미지를 네이버·인스타·유튜브와 동일한 것으로 교체
- [ ] 운영자명을 `김소요`로 통일
- [ ] 소개 문구 변경
  - `직접 써보고, 가보고, 먹어본 경험을 정보 중심으로 정리합니다`
  - `소비요정 김소요의 검색형 소비 기록`
- [ ] 스킨을 가독성 중심으로 변경
- [ ] 모바일 화면 점검 (애드센스 수익 대부분이 모바일에서 나온다)

### 주의 — 순서를 지킬 것

블로그 이름만 `김소요`로 바꾸고 223개 글을 그대로 두면, 검색으로 들어온
방문자가 `커피와비틀즈` 말투의 글을 `김소요` 브랜드로 읽게 된다. 브랜드
통일이 아니라 브랜드 혼선이 된다.

**이름 변경과 아래 3순위(과거 글 격리)를 같은 날 처리하는 것을 권한다.**

---

## 2순위 — 검색 인프라 점검 (1~2시간)

- [ ] 구글 서치 콘솔 소유 확인 상태 점검, 사이트맵 재제출
- [ ] 네이버 서치어드바이저 상태 확인
- [ ] 애드센스 광고 노출 정상 여부 확인 (2년 방치 상태라 코드가 끊겼을 수 있다)
- [ ] `ads.txt` 유효성 확인
- [ ] 새 글 1건 발행 후 색인 요청 → 며칠 내 색인되는지 확인

### 주의 — 애드센스 정책 리스크

2년 방치된 블로그에 갑자기 재가공 글이 쌓이면 정책 검토 대상이 될 수 있다.
두 가지를 확인한다.

- **저품질 콘텐츠**: 정보 가치가 거의 없는 과거 글이 다수 남아 있으면
  "가치 없는 콘텐츠" 항목에 걸릴 수 있다. 삭제는 안 해도 색인 제외는 검토한다.
- **재사용 콘텐츠**: 네이버 원문을 그대로 옮기면 정책 위반이다. 도구의
  `도입부 새로 작성` / `제목 완전 변경` 검수를 통과한 글만 올린다.

## 3순위 — 과거 글 격리 (1~2시간)

기존 URL은 가능한 한 유지한다. 삭제가 아니라 **분류와 안내**로 처리한다.

- [ ] 서치 콘솔에서 최근 3~6개월 검색 유입이 있는 글 목록 추출
- [ ] 유입이 있는 글은 그대로 유지 (건드리지 않는다)
- [ ] 나머지 글을 `예전 기록` 카테고리로 이동
- [ ] 오래된 정보성 글 상단에 안내 문구 추가
  - `이 글은 OOOO년에 작성했습니다. 최신 정보는 공식 채널에서 확인해 주세요.`
- [ ] 현재 브랜드와 심하게 충돌하는 글은 비공개 또는 아카이브 검토
- [ ] 저품질 글은 일괄 삭제하지 않고, 필요하면 `noindex`로 색인만 제외

## 4순위 — 새 카테고리 생성

| 대분류 | 하위 |
| --- | --- |
| 굳이 가봄 | 여행, 아이와 가볼 곳, 숙소 |
| 맛집카페 | 맛집, 카페 |
| 굳이 사봄 | 생활용품, 육아용품, 쇼핑, 이케아·코스트코 |
| 정보정리 | 이용방법, 주차·예약, 비교·팁 |
| 예전 기록 | 기존 티스토리 글 보관 |

- [ ] 위 구조로 카테고리 생성
- [ ] 메뉴에 노출할 항목 정리 (`예전 기록`은 메뉴에서 숨기는 편이 낫다)

## 운영 중 계속 확인할 것

- [ ] **협찬 글은 기본 제외.** 네이버 체험단·협찬 계약에 타 플랫폼 재게시
      금지나 독점 조항이 있는 경우가 많다. 계약서를 확인하지 않은 글은 옮기지
      않는다. 이건 검수 도구가 판단할 수 없다.
- [ ] **이미지를 그대로 재업로드하지 않는다.** 같은 파일을 그대로 올리면
      중복 신호가 된다. 리사이즈해서 새로 내보내고 파일명도 바꾼다.
- [ ] **네이버에서 티스토리로 링크를 걸지 않는다.** 티스토리 → 네이버 방향만
      건다. 반대로 걸면 본진 트래픽이 새어 나간다.
- [ ] 글당 추가 작업 시간이 10분을 넘기기 시작하면 이미지 수를 더 줄인다.
      실제 시간은 글쓰기가 아니라 **이미지 재업로드**에서 늘어난다.

## 성공 기준

방문자 수가 아니다.

- [ ] 네이버 블로그 운영에 지장이 없다
- [ ] 티스토리 추가 작업이 글당 10분 내외다
- [ ] 브랜드가 `소비요정 김소요`로 통일됐다
- [ ] 기존 223개 글과 애드센스 자산을 버리지 않았다
- [ ] 검색형 글이 누적된다
- [ ] 발행 전 사람이 반드시 검수한다
- [ ] 애드센스 수익이 나더라도 본진보다 티스토리가 우선되지 않는다
